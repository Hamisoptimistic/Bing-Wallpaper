Frequently Asked Questions

Everything you need to know about AutoScape and how it works on Windows.

How does AutoScape operate with 0 MB idle RAM? +
AutoScape registers a native Windows Scheduled Task via Task Scheduler instead of leaving a memory-heavy app running in the background. When your scheduled time arrives (e.g. Daily or Hourly), Windows silently invokes a 1-second native script, updates your wallpaper, and immediately terminates.
Can I have different wallpapers on my Desktop and Lock Screen? +
Yes! AutoScape features independent source routing. For example, you can set your Desktop to fetch fresh Wallhaven 4K Nature imagery while your Lock Screen displays the daily Microsoft Bing photography.
Is the PowerShell one-liner safe to run? +
Yes! The one-liner (irm ... | iex) downloads install.ps1 directly from our open-source GitHub repository, extracts it to your local AppData folder, and creates standard shortcuts. There is no obfuscated code, and everything is visible in public GitHub commits.
Do I need API keys for Wallhaven or Pexels? +
Wallhaven works completely keyless out-of-the-box for all SFW Nature wallpapers. Pexels offers a free API key with generous limits on their website, which you can paste directly into AutoScape's Preferences popup.
Does it support multiple monitors? +
Yes, AutoScape supports all native Windows wallpaper fit styles including Fit, Fill, Stretch, Center, and Span across multi-monitor setups.
Does AutoScape require administrative privileges? +
No. AutoScape is designed to operate entirely in standard user space (%LOCALAPPDATA%). Changing desktop wallpapers and creating scheduled tasks for the current user requires no administrator rights or UAC prompts.
Will it work on both Windows 10 and Windows 11? +
Yes. AutoScape is fully compatible with 64-bit editions of Windows 10 and Windows 11 using built-in Windows PowerShell 5.1 and .NET framework components.
How do I uninstall or remove the auto-rotation task? +
Simply open AutoScape and toggle the Auto switch to OFF. This cleanly deletes the Windows Scheduled Task. To remove the files, delete the %LOCALAPPDATA%\AutoScape folder.
